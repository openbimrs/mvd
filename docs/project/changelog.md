## 0.1.0 - 2026-09-27

The initial release establishes the pure-Rust typed mvdXML 1.1 model, bounded namespace-aware codec, deterministic writer, parameter-expression and nested-rule evaluator, fixed-schema and graph/business validator, authored fixture, repository gates, and documentation site.

Releases are published from CI through crates.io trusted publishing. See [PUBLISHING.md](https://github.com/openbimrs/mvd/blob/main/PUBLISHING.md) for the release and provenance checklist.
